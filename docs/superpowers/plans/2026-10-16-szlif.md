# Szlif Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Szlif: a local web page that rewrites Polish text with Bielik (via Ollama or an OpenAI-compatible server), cleans hidden characters, shows before/after side by side with a numbers guard, and ships with an installer, a README with macOS screenshots, and a private GitHub repo.

**Architecture:** One CLI entry `szlif.py` and a package `szlif_core/` of small stdlib-only modules. All logic is in Python and unit-tested: cleaner, guard, diff view, model backends, rounds, local HTTP server, and installer. The page `strona.html` only renders JSON the server computes. The browser drives the rounds one HTTP call at a time, so it can show progress and abort.

**Tech Stack:** Python 3.9+ standard library only (`http.server`, `urllib`, `difflib`, `unicodedata`, `unittest`), and a single HTML file with inline CSS/JS. Ollama as the model runtime. GitHub Actions for CI.

**Spec:** `docs/superpowers/specs/2026-10-16-szlif-design.md`. Read it first; section numbers below (§) refer to it.

## Global Constraints

- **Python floor is 3.9.** Use no `match` statement and no `X | Y` types at runtime; use `typing.Optional`, `List`, `Dict` and `Tuple`. Verify locally with `/usr/bin/python3` (3.9.6).
- **Standard library only.** No pip packages, no CDN, no web fonts, and the page works offline.
- **Platforms are macOS and Windows.** The Windows command is `py szlif.py`. Console output must not crash on Polish letters under a cp1252 console.
- **The local server binds `127.0.0.1` only.** The model server address comes only from `--serwer` or the `SZLIF_SERWER` environment variable, and the API key only from `SZLIF_API_KEY`.
- **Nothing the user pastes is written to disk or logs.** The server prints no request logs.
- **Language split.** UI copy, CLI messages and errors are in Polish. Code identifiers are in English. JSON keys between page and server are in Polish, exactly as named in Task 6.
- **Feature names, verbatim.** Use „przepisywanie Bielikiem” and „czyszczenie ukrytych znaków”. Never write „usuwanie znaków wodnych AI” or claim to defeat detectors or statistical watermarks.
- **No traces of the author's company, clients, internal paths or ticket keys anywhere,** history included. All example texts are invented. The forbidden-names list lives outside the repo (Task 11).
- **Commit identity:** `Marek Borowka <8522814+akworob@users.noreply.github.com>`, set with repo-local `git config` in Task 1. Every commit message ends with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **License:** MIT, `Copyright (c) 2026 akworob`.
- **No `gh repo create`, `git push` or visibility change without the user's explicit "tak" in chat** for that exact action (Task 11).
- **Test commands:** `python3 -m unittest discover -s tests -v` (any Python ≥3.9) and `/usr/bin/python3 -m unittest discover -s tests` (the 3.9 floor), both run from the repo root.

## Review Focus

1. **Model server down or model missing at start.** The page still loads, „Tylko wyczyść znaki” works, and a banner says what to run. *(Task 6 `test_stan_reports_backend_error`, Task 9 smoke.)*
2. **Text pasted from Word, with `\r\n` and NBSP.** It produces no phantom diffs; only the NBSP pills show. *(Task 6 `test_widok_normalizes_newlines`.)*
3. **Empty, whitespace-only or over-limit text.** The user gets a Polish 400/413 JSON message, never a stack trace. *(Task 6 `test_runda_rejects_empty`, `test_runda_rejects_too_long`.)*
4. **Default port taken, e.g. a second instance.** Szlif falls back to a free port and prints the real URL. *(Task 6 `test_busy_port_falls_back`.)*
5. **Model slower than the timeout.** The user gets a Polish timeout message, and the server keeps serving. *(Task 4 `test_timeout_message`, Task 6 `test_runda_backend_error_is_502`.)*

- [ ] **Step 3: Implement `find_values` and `check` in `szlif_core/guard.py`.**
  - **A value is:**
    - an ISO date `\d{4}-\d\d-\d\d`, or a dotted date `\d{1,2}\.\d{1,2}\.\d{2,4}`, or a time `\d{1,2}:\d\d`; or
    - an optional sign, then digits (thousands may be grouped by a space, NBSP or NNBSP), an optional decimal part `[.,]\d+` kept *as written*, and an optional unit after at most one space.
  - **Sign:** `-`, `+` or `−`, only at the start of the text or after a space or `(`. It never counts after a digit, so `10-20` is a range.
  - **Units are canonicalised:**

    | written | canonical |
    |---|---|
    | `%`, `procent\w*`, `proc.` | `%` |
    | `zł`, `zl`, `złot\w*`, `PLN` | `zł` |
    | `gr`, `grosz\w*` | `gr` |
    | `€`, `EUR`, `euro` | `EUR` |
    | `$`, `USD`, `dolar\w*` | `USD` |
    | `tys.`, `tysi\w*` | `tys.` |
    | `mln`, `milion\w*` | `mln` |
    | `mld`, `miliard\w*` | `mld` |
    | `s`, `sek.`, `sekund\w*` | `s` |
    | `min`, `min.`, `minut\w*` | `min` |
    | `h`, `godz.`, `godzin\w*` | `godz.` |
    | `dni\w*`, `dzień`, `dnia` | `dni` |
    | `tydz.`, `tydzień`, `tygodni\w*` | `tydz.` |
    | `mies.`, `miesi\w*` | `mies.` |
    | `r.`, `rok\w*`, `roku`, `lat\w*`, `lata` | `lat` |
    | `szt.`, `sztuk\w*` | `szt.` |
    | `km`, `kilometr\w*` | `km` |
    | `kg`, `kilogram\w*` | `kg` |
    | `m`, `cm`, `mm`, `g`, `t`, `l`, `ml` | as written |
    | `stycznia` … `grudnia` | as written |

    A multiplier (`tys.`, `mln`, `mld`) may take one more unit word (`2,5 mln zł`).
  - **Symbolic unit:** the next token contains an uppercase letter, a digit or one of `°²³`, and is not a capitalised ordinary word (one uppercase letter followed by ≥2 lowercase letters).
  - **List markers** `^\s*\d{1,2}[.)](?=\s)` (multiline) are ignored.
  - **The key** is the sign, the digits with the group spaces removed, the decimal part, then a space and the canonical unit if there is one.
  - **`check`:**
    - compare the two `Counter`s of keys;
    - for the missing keys, take spans from the original;
    - add `too_long` when `len(output.split()) > 3 * len(original.split()) + 8`, and `cut` when `cut` is true.
  - **Message copy, verbatim:**
    - values: `Liczby, jednostki lub daty różnią się od oryginału. Sprawdź przed użyciem.`
    - cut: `Odpowiedź modelu została ucięta. Podziel tekst na części.`
    - too_long: `Wynik jest dużo dłuższy od tekstu. Model mógł odpowiedzieć na tekst zamiast go przepisać.`

  - normalise `\r\n` and `\r` to `\n` in `tekst`, `biezacy` and `wynik`;
  - `Host` must be `127.0.0.1:<port>` or `localhost:<port>`, else 403;
  - for a POST, an `Origin` header, if present, must be `http://127.0.0.1:<port>` or `http://localhost:<port>`, else 403;
  - for a POST, `Content-Type` must be `application/json`, else 415;
  - a body over 1 MB gets 413.
- **Other errors:**
  - empty or whitespace-only `tekst`: 400 `Wklej tekst.`;
  - `len(tekst) > MAX_CHARS`: 413 `Tekst ma {n} znaków, limit to 12 000. Podziel go na części.` (the count `n` is grouped with a space);
  - invalid JSON: 400 `Nieprawidłowe zapytanie.`;
  - `BackendError`: 502 with its message.
- **`log_message` prints nothing.**
- **CLI:** `szlif.py [--serwer URL] [--rodzaj ollama|openai] [--model NAZWA] [--port N] [--bez-przegladarki]` and `szlif.py instaluj [--serwer URL]`.

  - Before any print, `stdout`/`stderr` are reconfigured to `utf-8`, `errors="replace"`.
  - Ctrl+C prints `Zatrzymano.` and exits with 0.
